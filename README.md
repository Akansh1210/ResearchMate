# TeachSphere 🎓

**Empowering teachers. Transforming classrooms.**

TeachSphere is a mobile-friendly teacher education platform prototype for B.Ed. and M.Ed. students. It brings together foundational learning modules, practical teaching tools and reflective practice.

## Version 1 features
- Responsive dashboard and navigation
- Six introductory teacher education modules
- Mark modules as explored and track progress
- Lesson Plan Builder with local saving
- Reflective Teaching Journal with local saving
- AI Teaching Assistant preview (not connected to an AI service yet)

## Run locally
1. Download and extract the project.
2. Open the `TeachSphere` folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension, or open it directly in a browser.

## Educational note
The module summaries are introductory prompts, not a substitute for prescribed readings, official policy documents or institutional guidance. Verify policy details and align resources with the relevant university curriculum before academic use.

## Privacy note
Version 1 stores saved plans, reflections and progress in the current browser using localStorage. Avoid entering sensitive personal or student information. Clearing browser data may remove saved entries.
